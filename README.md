# llama.cpp GUI Launcher
跨平台llama.cpp可视化启动器，支持Windows/macOS，低内存高性能，让本地大模型使用零门槛。

## ✨ 特性
- 🎨 美观易用的可视化UI，无需记住任何命令行参数
- 🤖 自动扫描本地GGUF格式模型，一键选择启动
- ⚙️ 全参数可视化配置：上下文长度、线程数、GPU层offload、推理参数（温度、top_p等）
- 📊 实时监控：模型上下文使用情况、token生成速度、电脑CPU/内存/GPU性能监控
- 💬 内置对话窗口，启动后直接可以和模型聊天
- 🪶 极低内存占用：基于Rust + Tauri开发，比Electron类工具内存占用低80%以上
- 🖥️ 原生跨平台支持：Windows/macOS双端兼容，单文件打包无需预装运行时

## 🛠️ 技术栈
- **后端**：Rust + Tauri + llama-cpp-rs（llama.cpp的Rust绑定）
- **前端**：React + TypeScript + TailwindCSS
- **打包**：Tauri原生打包，输出exe/dmg单文件安装包
