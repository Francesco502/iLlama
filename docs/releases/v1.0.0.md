# iLlama v1.0.0

iLlama v1.0.0 is the first release of the lightweight desktop launcher for
running local GGUF models through `llama-server`.

## Highlights

- Native-style macOS desktop UI for selecting GGUF model directories.
- Recursive GGUF scanning inside user-selected folders only.
- Lightweight GGUF metadata reading without loading model weights.
- `llama-server` path detection and user-selected binary support.
- Parameter presets, validation, command preview, health checks, and auto-port selection.
- Start, stop, logs, runtime status, and OpenAI-compatible streaming chat.
- Optional image request formatting and `mmproj` projector arguments.

## macOS Distribution Notes

The v1.0.0 app is a launcher-only release. It does not bundle `llama-server`.
Install `llama-server` separately or select an existing executable from iLlama.

Public macOS distribution should use the signed and notarized DMG generated by:

```bash
APPLE_SIGNING_IDENTITY="Developer ID Application: <Name> (<TEAMID>)" \
APPLE_NOTARY_PROFILE=illama-notary \
npm run release:macos
```

If the release is built without a Developer ID certificate, macOS will treat the
DMG as unsigned/unnotarized.
