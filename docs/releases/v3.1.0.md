# iLlama v3.1.0

iLlama v3.1.0 keeps the V3 launcher-first direction and focuses on multimodal GGUF startup support, clearer smoke-test feedback, and cross-platform release hygiene.

## Highlights

- Multimodal projector workflow improvements:
  - Same-directory `mmproj` candidates are detected next to the selected GGUF model.
  - A single compatible `mmproj` candidate can be selected automatically.
  - Projector status is visible before launch.
  - Image requests are preflighted against runtime capability before being sent.
- Smoke-test chat now shows sent image and text attachments in the message thread, so multimodal test requests have visible confirmation.
- Attachment entry points are disabled while the runtime is unavailable or streaming.
- The bottom status bar remains on one line on narrow screens by scrolling horizontally instead of wrapping metric labels.
- macOS Dock reopen handling is compiled only on macOS, keeping Ubuntu and Windows Rust CI green.

## Notes

- iLlama still uses the external `llama-server` strategy. No `llama-server` sidecar is bundled in this release.
- For image recognition, use a vision GGUF model with the matching `mmproj` file from the same Hugging Face GGUF repository when possible.
- V3 remains a launcher and connection handoff tool, not a full chat workspace.
