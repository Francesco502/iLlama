# iLlama v3.0.0

iLlama v3.0.0 is a launcher-first redesign. The app now focuses on running local GGUF models through `llama-server`, exposing a clean OpenAI-compatible endpoint, and handing conversation workflows to dedicated clients.

## Highlights

- New `运行 / 连接 / 测试` navigation.
- Launcher-first model: scan GGUF files, configure `llama-server`, start/stop the runtime, inspect logs, and copy connection details.
- `最大能力 / 自定义` parameter modes:
  - Maximum capability derives `ctxSize` from GGUF metadata and auto-sets smoke-test output length.
  - Custom mode exposes sliders for context length and output length.
- OpenAI-compatible connection panel:
  - Base URL
  - API Key
  - Model
  - Chat Completions URL
  - JSON copy payload
  - `/health` and `/v1/models` connection check
- External client profiles for Chatbox, Cherry Studio, Open WebUI, AnythingLLM, and custom clients.
- Transient smoke-test chat for validating that the current runtime responds.
- Explicit V2 legacy history export bundle for users migrating away from the removed workspace.
- V3 settings no longer enable persistent chat history by default.
- macOS window and background lifecycle optimization: window close (X) hides the window to the background (remains in Dock), clicking the Dock icon restores focus, and full quit (Cmd+Q/Dock quit) reliably kills all background `llama-server` processes.
- Clarify status bar toggle description to explicitly refer to the top macOS system menu bar (wifi, battery, etc.).


## Migration Notes

V3 removes the full chat workspace from the primary UI. Existing V2 chat history files are not deleted, but iLlama no longer treats them as an active first-class product surface.

Users who need a copy of old V2 history can use `连接` → `导出 V2 历史`. The export reads the legacy `chat-history` directory and writes a JSON bundle under `chat-history/exports/`.

Recommended V3 workflow:

1. Select a GGUF model directory.
2. Select a model and launch `llama-server`.
3. Open the `连接` page.
4. Copy the OpenAI-compatible connection details into Chatbox, Cherry Studio, Open WebUI, AnythingLLM, or another compatible client.
5. Use `测试` only for a quick local smoke test.

`maxTokens` in iLlama controls only the built-in smoke test request. External clients connected to `/v1/chat/completions` keep their own output-length controls.
